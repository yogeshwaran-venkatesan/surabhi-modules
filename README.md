# Surabhi Modules — 3D Landing Page

Premium 3D interactive landing page for **Surabhi Modules**, interior design studio in Kakkanad, Kochi.

- `index.html` — the built, self-contained site (open directly or host on any static host / GitHub Pages).
- `src/` — source (markup parts, CSS, JS).
- `PROJECT_GUIDE.md` — full explanation of how the site works.

```bash
npm install
npm run build      # rebuilds index.html
npm run shots      # Playwright screenshots (desktop + mobile)
```
